#981 - Apply Teal UI Refresh
What & Why
Apply the approved reference styling while preserving accessibility and all established behavior. Globally update the shared --primary, --background, --card, and --card-border tokens, including their dark-theme redeclarations, for an app-wide consistent dark-green/off-white foundation; leave --foreground and --accent unchanged. Add a dedicated --brand-culinary token for approved dinner/culinary CTAs only. Use the supplied transparent har-gow mascot, add the approved frontend-only meal timeline, and add HStix note preset tags without introducing new backend models or replacing current FoodSnap logic.

Verified corrections to the requested assumptions: the advice popup has exactly three cards; daily habits are server-persisted with multiple offered choices but one completion per local day; current canvas/cards already use cream/off-white tokens; the navigation is already a gated five-item pill; and weekly report summaries do not contain meal names or timestamps.

The meal timeline will use the existing monthly meal-log endpoint, whose records already include the recorded time, local date, meal type, food name, and glucose-impact level. The report page will filter those real records to its displayed date range, sort by recorded time, and render 高影響/中影響/低影響 without sample data.
