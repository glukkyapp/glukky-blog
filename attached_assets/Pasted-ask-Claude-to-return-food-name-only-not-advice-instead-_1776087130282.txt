async getIngredientsByAlias(text: string, category: string): Promise<IngredientVocabulary[]> {
const normalised = text.trim().toLowerCase();
if (!normalised) return [];
const all = await db.select().from(ingredientVocabulary)
.where(eq(ingredientVocabulary.category, category));
return all.filter(v =>
v.internalId.toLowerCase() === normalised ||
v.labelEn.toLowerCase() === normalised ||
v.labelZh === text.trim() ||
v.labelYue === text.trim() ||
(v.aliases ?? []).some(a => a.toLowerCase() === normalised)
);
}

// ─── HELPER: Build canonical combo key ──────────────────────────────
function buildComboKey(foodName: string, portion: string, sauces: string[], toppings: string[]): string {
const sortedSauces = [...sauces].sort().join(",") || "none";
const sortedToppings = [...toppings].sort().join(",") || "none";
return `${foodName}|${portion}|${sortedSauces}|${sortedToppings}`;
}

Issue 5 — getFoodCombos does a full table scan
typescript

Problem: This loads the entire food_combos table into memory on every snap. Fine now with 100 dishes, but will degrade. Also does not use Postgres's index capabilities.

Fix:

typescript
async getFoodCombos(foodName: string): Promise<FoodCombo[]> {
  const normalised = foodName.trim().toLowerCase();
  // Use Postgres ilike for case-insensitive match
  return await db.select().from(foodCombos)
    .where(
      or(
        sql`lower(${foodCombos.foodName}) = ${normalised}`,
        sql`lower(${foodCombos.foodNameEn}) = ${normalised}`,
        sql`${normalised} = ANY(${foodCombos.foodNameAliases})`
      )
    );
}

Issue 8 — Step 3 sends image again to Claude unnecessarily
In Step 3, the image is sent a second time to Claude to get portion/sauce/extras. But you already identified the food name, and portion/sauce/extras for known combos come from your DB. Step 3 should only be triggered for unknown foods — and for unknown foods, Claude mostly guesses standard defaults anyway.

Consider: For Step 3, you can call Claude with text only (no image re-upload) since the food name is already known:

typescript
// Step 3 — text only, no image needed
const fullResponse = await anthropic.messages.create({
  model: "claude-sonnet-4-6",
  max_tokens: 200,
  system: `You are a Hong Kong food expert. Return typical default portion, sauces, and toppings for the named dish as JSON only.`,
  messages: [{
    role: "user",
    content: `What are the typical default portion, sauces, and extras for "${foodName}" in Hong Kong?`
  }]
});
This reduces image token cost on every Step 3 fallback call.
