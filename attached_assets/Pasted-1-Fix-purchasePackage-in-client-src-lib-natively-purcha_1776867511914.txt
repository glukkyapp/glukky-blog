1. Fix purchasePackage() in client/src/lib/natively-purchases.ts
Current bug: it returns success: true whenever there is no error and no explicit cancelled, even if the purchase sheet was dismissed and there is no active premium entitlement.

Required change:

In the purchase callback, treat the purchase as successful only if:

result.customerInfo exists, and

isPremiumFromCustomerInfo(result.customerInfo) returns true

Desired logic:

ts
purchases.purchasePackage(packageId, (result) => {
  const customerInfo = result?.customerInfo || null;
  const hasPremium = isPremiumFromCustomerInfo(customerInfo);

  if (result?.error) {
    resolve({ success: false, error: result.error });
  } else if (result?.cancelled) {
    resolve({ success: false, error: "cancelled" });
  } else if (customerInfo && hasPremium) {
    resolve({ success: true, customerInfo });
  } else {
    resolve({ success: false, error: "cancelled" });
  }
});
